### 2. **DataSet 配置详解**

#### 表格 DataSet（tableDS）

```typescript
export function tableDS(): DataSetProps {
  return {
    autoQuery: true,              // 自动查询（页面加载时自动调用）

    selection: 'multiple',        // 多选模式

      {
        name: 'demoType',
```

### 3. **useRequest Hook 使用**

```typescript
import { useRequest } from '@components/tarzan-hooks';

// 基本用法
const { loading, data, error, run } = useRequest(
  {
    url: '/api/v1/data',
    method: 'POST',
  },
  {
    manual: true,              // 手动触发（不自动执行）
    needPromise: true,         // 返回 Promise（可以 await）
    showNotification: true,    // 自动显示错误提示
  }
);

// 手动触发
const handleSave = async () => {
  const res = await run({ 
    params: { id: 1, name: 'test' },
    onSuccess: (data) => console.log('成功', data),
    onFailed: (err) => console.error('失败', err),
  });
};
```

```typescript
const handleRowSave = async (record) => {
  // 1. 验证字段
  const valid = await record.validate();
  if (!valid) return;
  
  // 2. 获取数据
  const data = record.toData();
  
  // 3. 判断新增还是编辑
  const isAdd = record.status === 'add';
  
  // 4. 调用接口
  const res = await (isAdd ? runSave({ params: data }) : runUpdate({ params: data }));
  
  // 5. 处理结果
  if (res && !res.failed) {
    notification.success({ message: '保存成功' });
    record.setState('editing', false);
    tableDs.query();  // 重新查询
  }
};
```

## 🔑 关键知识点总结

### 1. **useMemo 的作用**
- 防止 DataSet 重复创建
- 避免不必要的重新渲染

### 2. **DataSet 的状态**
- `status === 'add'`: 新增状态
- `status === 'update'`: 更新状态
- `record.getState('editing')`: 编辑状态

### 3. **常用方法**
- `tableDs.create({}, 0)`: 创建记录
- `tableDs.remove(record)`: 删除记录
- `tableDs.query()`: 查询数据
- `record.validate()`: 验证字段
- `record.toData()`: 获取记录数据
- `record.reset()`: 重置记录

## ❓ 常见问题

**Q: 为什么要用 useMemo 创建 DataSet？**  
A: 防止每次渲染都创建新的 DataSet，导致表格重新渲染和数据丢失。

**Q: manual: true 和 needPromise: true 的区别？**  
A: `manual: true` 表示不自动执行请求；`needPromise: true` 表示 run 方法返回 Promise，可以 await。

**Q: 表格内编辑和弹框编辑怎么选？**  
A: 简单字段用表格内编辑，复杂表单用弹框编辑。可以两者结合使用。

**Q: 如何处理接口报错？**  
A: useRequest 会自动处理错误提示，也可以用 try-catch 自定义处理。
